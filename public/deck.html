Strategic Tension08 / 15
Product Experience

The prototype experience: guided creation, not a mobile-only flow.

MerchForge proves the core interaction in a desktop web experience: describe the idea, choose a generated variant, refine with simple controls, and move to cart. This validates the intent → variant → constrained edit flow before building it into Spreadshirt.

Step 01

Generate and compare variants

Users do not start from a blank canvas. They get multiple layouts — text-only, text + icon, AI suggested, icon-led — then pick the direction that feels closest.

Step 02

Refine with constrained controls

The editor exposes the decisions that matter: product, color, icon, scale, position, size and quantity. It keeps the user in control without asking them to become a designer.

AI is the starterVariants create a first draft the user can react to.
Constraints create qualityControls stay production-aware instead of becoming a generic art tool.
Cart-ready by designThe flow keeps preview, refinement and purchase in one continuous path.

MerchForge

How the AI works: flexible language in, constrained output out.

The prototype keeps the strategic principle intact: AI interprets intent and explores design space, while deterministic gates protect inventory validity, print feasibility, and cart trust.

Flow 1 · Discover

Natural-language inventory discovery

User describes budget, color, material, quantity, or timing. The AI ranks filtered catalog items and explains why each recommendation fits.

Validated against:
ACP-shaped inventory schema, product availability, constraints, and graceful fallback logic.
Flow 2 · Create

Guided design generation

User specifies product, text, icon, colors, and size in any order. When enough context exists, the system generates three SVG variants and a live preview.

Controlled by:
readiness predicates for preview and add-to-cart, plus deterministic rendering to SVG.
Architecture

LLM-assisted, deterministic where it counts

The LLM returns structured JSON plus semantic layout tokens. A deterministic parser and renderer turn those tokens into consistent, inspectable SVG outputs.
